## 🚀 Running with Vite / Node.js (Optional Developer Mode)

If you prefer to run a local dev server with Vite:
```bash
npm install
npm run dev
```

To create a production build:
```bash
npm run build
```

## 🖼️ Instant 1-Click Media & Logo Setup

We have created an automated script to copy your uploaded Arnold logo and studio banners directly into the project:
1. Simply **double-click `copy_logo.bat`** in the project folder!
2. That automatically creates the `assets/` folder and copies `logo.png`, `banner.png`, and `poster.jpg`.
3. Refresh `index.html` in your browser to see your logo live!
